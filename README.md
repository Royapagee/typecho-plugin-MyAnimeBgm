# MyAnimeBgm——像展示照片一样展示你的追番！

把 [Bangumi](https://bgm.tv) 的追番收藏同步到 Typecho，在前台生成一面番剧墙的插件。

番剧名称、状态、观看进度、评分和封面都会拉到本地，封面额外做本地缓存，
解决 `lain.bgm.tv` 在国内访问受限导致的裂图。

## 功能

- 从 Bangumi API 拉取指定用户的收藏，存入 Typecho 数据表或插件目录下的 JSON
- 前台番剧墙：一次加载全部，筛选和搜索都在浏览器里即时完成
- 四种排序：追番状态 / 收藏更新时间 / Bangumi 评分 / 番剧名称
- 封面本地缓存，由服务器并发下载，并随缓存过期自动刷新
- 后台「追番管理」面板：同步状态、图片缓存管理、番剧数据浏览
- 主题配色自动适配（Jasmine 跟随主题色板，其它主题自动回退）

## 系统要求

- Typecho 1.3.x
- PHP **8.0+**（用到了 `match`、`str_contains()` 等）
- cURL 扩展
- `cache/` 与 `covers/` 目录可写，且 `covers/` 能被浏览器直接访问

## 安装与前台基本使用

1. 下载插件。
2. 把插件解压到 `usr/plugins/` 下，目录名必须是 `MyAnimeBgm`（Typecho 按目录名定位插件，改名会导致插件无法启用）。
3. 进入文件夹 `theme`，复制一份 `page-bangumi.php` 到你使用的主题的目录下。
4. 后台 → 控制台 → 插件 → 启用 **MyAnimeBgm**
5. 进入插件**设置**，填好 **用户 ID**，保存
   - 保存时会立即同步一次
6. 后台 → **追番管理** → 「图片缓存」→ 点 **缓存缺失图片**，等封面下载完（需网络支持）
7. 在 **独立页面** 新增 独立页面，自定义模板选择 **番剧页面**。保存，插件生效

## 设置项

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| Bangumi API 地址 | `https://api.bgm.tv` | 也可填自建反代地址 |
| 用户 ID | `sai` | Bangumi 用户名，**只接受用户名，不接受数字 UID** |
| Access Token | 空 | 收藏私密时才需要 |
| 收藏分类 | 动画 | 对应 API 的 `subject_type` |
| 缓存数据库类型 | 数据库 | 数据库写入 Typecho 数据表，文件则写入 `cache/` 下的 JSON |
| 缓存（自动刷新）时间 | 12 小时 | 填 `0` 表示每次访问都刷新 |
| 展示顺序 | 按追番状态 | 另可选更新时间 / 评分 / 名称 |
| 页面标题 | 我的追番 | 路由页面与兜底外壳的标题 |
| 页面访问路径 | `/bangumi` | 保存后立即生效 |

保存设置时会顺带同步一次数据，所以「保存」即「保存并刷新」。

## 后台管理页面

三块面板：

- **同步状态** — 用户、缓存类型、刷新间隔、番剧数量、最近同步时间
- **图片缓存** — 已缓存封面数 / 占用空间 / 待缓存张数，提供「缓存缺失图片」
  「全部重新缓存」「清理无主图片」「清空图片缓存」四个操作
- **番剧数据** — 表格列出全部条目

工具栏可执行「立即刷新」（立刻拉一次最新收藏）、「清空数据」等操作。

## 常见问题

**前台裂图 / 只有番剧名没有封面**

- 封面还没缓存或者客户端访问受限，到「追番管理 → 图片缓存」点「缓存缺失图片」。

**提示「请先在后台插件设置里填写 Bangumi API 地址与用户 ID」**

- 插件还没配置成功，回设置页填好再保存。

**访问 `/bangumi` 是 404**

- 路由在插件启用时注册。改过访问路径后重新保存一次设置即可，同时确认站点伪静态正常。

**想立刻看到最新追番**

- 后台点「立即刷新」，或把刷新时间设小（填 `0` 表示每次都刷新）。

**收藏是私密的，同步不到**

- 在设置里填 Access Token。

**换了主题，配色或样式不对**

- 目前仅针对 **Jasmine** 主题有专门适配，其余情况自动回退到插件自带主题，望知悉。

## 文件结构

```text
MyAnimeBgm/
├── Plugin.php              插件入口：启用/停用、配置表单
├── Api.php                 Bangumi API 客户端
├── Store.php               番剧数据存取（数据库 / 文件两种后端）
├── ImageCache.php          封面本地缓存（并发下载）
├── View.php                前台数据与格式化工具
├── Chrome.php              主题外壳装配
├── Theme.php               主题判定，决定配色档位
├── Action.php              后台面板的 AJAX 动作
├── Widget/Page.php         /bangumi 路由的页面组件
├── theme/page-bangumi.php  主题独立页面模板（复制到主题目录使用）
├── template/               前台与后台模板
├── static/bangumi.css      前台样式
├── cache/                  运行状态与 JSON 缓存（拒绝直接访问）
└── covers/                 封面图片缓存（需可被浏览器访问）
```

## 备注

- 图片缓存存放于 `usr/plugins/MyAnimeBgm/covers/{条目ID}.jpg`，缓存的是 400px 中等图。
  目录下自带 `.htaccess` 只用于关闭目录列表，**不要**把整个目录 deny 掉。

- 「文件缓存」模式下 `cache/bangumi.json` 是明文 JSON，nginx 用户请自行加一条
  `location ~* /usr/plugins/MyAnimeBgm/cache/ { deny all; }`。

- 停用插件不会删除数据表，重新启用后数据仍在（但插件配置会被 Typecho 清掉，需重新保存）。
